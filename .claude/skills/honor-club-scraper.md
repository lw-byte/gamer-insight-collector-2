# Honor Club Scraper Skill

抓取荣耀俱乐部 WIN系列游戏体验板块的用户反馈数据，并进行功能特性和游戏两个维度的分类分析。

## 工作流程

### Step 1: 抓取数据

```bash
python honor_club_scraper.py
```

输出:
- `honor_club_data.json` - 原始数据
- `honor_win_threads.xlsx` - Excel格式
- `honor_win_threads.html` - HTML格式

### Step 2: 分类分析

```bash
python classify_posts.py
```

输出:
- `classified_posts.json` - 分类后的数据
- `classified_posts.xlsx` - 分类后的Excel
- `classified_by_feature.xlsx` - 按功能分类的Excel
- `classified_by_game.xlsx` - 按游戏分类的Excel
- `classification_report.md` - 分析报告

## 关键洞察

1. **帧率适配是最大痛点** - 36.7%的反馈与此相关
2. **三角洲行动最受关注** - 占游戏类反馈的50%+
3. **用户核心诉求**:
   - 帧率与画质不可兼得
   - WIN RT差异化对待不满
   - 希望极客中心下放
   - 新游戏预适配需求
