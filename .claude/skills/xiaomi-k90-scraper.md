# Xiaomi K90 Scraper Skill

抓取小米社区 K90系列（K90 Max、K90/PM）圈子中的游戏相关帖子，并进行功能特性和游戏两个维度的分类分析。

## 工作流程

### Step 1: 抓取数据

```bash
python mi_k90_scraper.py
```

输出:
- `mi_k90_data.json` - 原始数据
- `mi_k90_threads.xlsx` - Excel格式
- `mi_k90_threads.html` - HTML格式
- `mi_k90_report.md` - 分析报告

## API结构

小米社区使用 `api.vip.miui.com` 接口：

```
GET https://api.vip.miui.com/mtop/planet/vip/home/discover
```

参数:
- `dotEntrance=CIRCLE_DETAIL` - 圈子详情入口
- `circle=K90 Max` 或 `circle=K90/PM` - 圈子名称
- `pageNum=N` - 页码
- `pageSize=50` - 每页条数

## 关键洞察

1. **帧率适配是最大痛点** - 43.8%的游戏相关反馈与此相关
2. **三角洲行动和异环最受关注** - K90用户主要关注这两款游戏
3. **用户核心诉求**:
   - 高帧率游戏体验（165帧）
   - 新游适配优化
   - 散热和温控表现
